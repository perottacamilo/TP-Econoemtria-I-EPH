#Analisis del salario - EPH (4to trimestre 2025)

##EPH
La Encuesta Permanente de Hogares es una encuesta que realiza el INDEC trimestralmente a miles de hogares donde se miden variables socioeconomicas como el empleo, la desocupacion, el salario y las condiciones de vida.

##Objetivos del trabajo
El trabajo  consiste en utilizar fundamentos estadisticos y econometricos para el analisis de interes, en este caso el salario, realizando estimaciones, y proyecciones utilizando la base de microdatos del cuarto trimestre de 2025

##Lenguaje##: RStudio 
##Base de datos##: Microdatos EPH individual.
##Modelos utilizados##: Minimos Cuadrados Ordinarios, Log-Lin
